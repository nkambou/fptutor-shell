# Grille de relevé

Ce relevé porte sur le dispositif, pas sur les personnes. Le certificat
d'éthique n'étant pas délivré, ces notes servent à corriger le tuteur et ne
seront pas exploitées comme données de recherche.

Aucun nom, aucun code permanent, aucun pseudonyme, aucun numéro de poste. Si une
observation ne se comprend qu'en désignant une personne, elle n'entre pas dans
la grille.

## Blocages

Une ligne par blocage observé, c'est-à-dire un étudiant arrêté plus de deux
minutes sans soumettre.

| Minute | Exercice | Ce qui bloque | Aide demandée | Dénouement |
|---|---|---|---|---|
| | | | | |

Dans « ce qui bloque », distinguez trois natures : la consigne n'est pas
comprise, l'interface n'est pas comprise, le problème OCaml n'est pas résolu.
C'est la distinction la plus utile pour la suite.
